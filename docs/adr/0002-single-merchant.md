# 單一商家，不做多租戶

Holdfast 只服務一個商家；商家底下可以有多個資源，但不存在「商家」這個可被複製的層級。多租戶會牽動資料隔離、管理者權限範圍與資料庫切分，是事後很難補、也很難拆的決定；目前沒有第二個商家，為假想需求付出這些成本不划算。

**Considered Options:** 一開始就以商家 ID 切分所有資料（保留未來多租戶）——被否決，因為那會讓每一條查詢與權限檢查都多一個維度，卻沒有任何現實需求驗證它。

**Falsified if:** 出現第二個要使用 Holdfast 的商家，或 `CONTEXT.md` 開始需要「商家」這個詞。
