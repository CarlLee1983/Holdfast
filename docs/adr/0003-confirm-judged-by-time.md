# 確認能否成立以時間比較判定，釋放不參與

一筆保留能否被確認，只看確認寫入的那一刻是否早於保留的到期時間。釋放（把過期保留的名額還給時段）只是清理，不是判定：即使釋放還沒跑，過期的保留也不能確認；即使釋放晚到，也不能讓已經成立的確認失效。這讓正確性不依賴背景工作的準時與否——背景工作可能延遲、重送或失敗，而時間比較不會。

**Consequences:** 計算時段剩餘名額時，必須把已過期但尚未釋放的保留視為不占名額；否則釋放延遲會造成假性額滿。

**Falsified if:** 平台提供的排程或佇列能保證在到期時間點準時且恰好一次執行，使釋放可以成為判定來源；或 `CONTEXT.md` 對「確認」「釋放」的定義改變。
